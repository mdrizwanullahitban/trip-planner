# Trip Planner

C# AI trip planner using Blazor WebAssembly and ASP.NET Core.

## Starter project
The complete starter source is available as a ZIP in the ChatGPT conversation. Extract its contents into this repository to continue development.

Features: 8-step questionnaire, Four Wheeler default, AI itinerary generation, Google Maps links, responsive UI.

Run the API with `dotnet run --project TripPlanner.Api --urls http://localhost:5000` and the client with `dotnet run --project TripPlanner.Client --urls http://localhost:5100`. Set `OPENAI_API_KEY` on the server.
